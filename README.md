# Rebuilt

Rebuilt is a Blender 5.2.x addon from Difffuse Studio for retopology, seams, UV unwrapping, packing, texture baking and export to Unity, Unreal and Godot.

The addon integrates AutoRemesher Fine Details for retopology, CleanSeams for seam generation and unwrapping, and UVPack for packing. Blender's QuadriFlow is available as an alternative or fallback. AutoRemesher is independently maintained.
